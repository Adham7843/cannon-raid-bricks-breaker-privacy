# Privacy Policy — Cannon Raid Bricks Breaker

Hosted at: **https://adham7843.github.io/cannon-raid-bricks-breaker-privacy/**

This repository hosts the published privacy policy for **Cannon Raid Bricks Breaker** by
AZ Group (AZ GP Games).

- `index.html` — the published page (this is what Play Console links to)
- `PRIVACY.md` — the same policy as Markdown, for the repo and for editing

## Editing

Edit `PRIVACY.md`, then mirror the change into `index.html` and push. GitHub
Pages rebuilds automatically.

Keep these true when you edit:

- AdMob is the only third-party SDK in the shipped build
- Rewarded ads only — no interstitials
- No accounts, no servers, all game data is local
- The permission list matches the shipped `AndroidManifest.xml`
